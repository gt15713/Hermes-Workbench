# QQ 与微信私聊收录

Workbench 通过 Hermes 官方插件命令支持已授权的 QQ C2C、QQ 群和微信私聊。聊天历史保持平台隔离，任务通过 `WB-XXXXXXXX` 编号共享状态。

```text
/wb 任务 <内容>
/wb 待回看 <内容或链接>
/wb 待验证 <内容>
/wb 随想 <内容>
/wb 查看 <任务编号或标题>
/wb 继续 <任务编号> <补充内容>
/wb 完成 <任务编号或标题>
/wb 归档 <任务编号或标题>
/wb 重开 <任务编号或标题>
/wb 延期 <任务标题> <YYYY-MM-DD>
```

任务创建后返回稳定编号。后续在另一 QQ 账号或微信中携带该编号，即可更新同一任务，不依赖 Hermes 会话上下文。

- `/wb` 在 Hermes pairing/allowlist 授权后调用。
- 收录只登记，不执行任务。
- 命令指纹用于幂等，重放不会重复建卡。
- 任务只记录 `qq`、`weixin` 或 `messaging`，不记录 OpenID。
- 写入失败返回真实失败，不发送虚假成功回执。
